## 当前平台能力

- QQ：保存官方 HTTPS 链接，在官方页面登录与播放。本站不能判断平台登录是否成功，不显示伪造的“已连接”。
- Spotify / 网易云：`MUSIC_PROVIDERS` 中保留独立适配配置，默认未启用。不会把未接入功能作为可用按钮。
- 站内个人歌单连接：未完成。需要平台针对本项目的官方应用与授权方案；QQ 普通网页登录不代表本站获得歌单读取权限。
- 当前已在官方页面核实 [开发者平台](https://y.qq.com/music_developer/#/) 与 [H5 授权文档](https://y.qq.com/music_developer/#/docs/openid#/overview)；需要主体与应用审核。普通桌面浏览器完整播放是否获准，须以平台对本项目的确认和应用权限为准。见 [申请步骤](QQ-MUSIC-ACCESS.md)。

## 自动验证

- `npm run check`：JavaScript 语法、入口资源、重复 HTML ID。
- `npm test`：15 项测试；在原有计时、迁移、账号隔离与权限基础上，新增四场景音轨一致性、咖啡馆新构图、音乐授权与播放权限门控、未开通 API 拒绝假授权的验证。
- `npm run db:local`：真实 Wrangler 本地 D1 执行初始迁移。
- `npm run test:integration`：真实 Worker/D1/Durable Object，双账号双 WebSocket；场景/状态同步、权限拒绝、共同开始、共享/私人歌单、断线重连、解散和退出。
- 浏览器验证与截图：本机 Worker 预览验证待办新增/完成/删除、关联专注、收起与刷新恢复计时、雨声播放状态及场景切换。390px 手机视口复核无横向溢出；[桌面截图](references/desktop-preview.png)、[手机截图](references/mobile-preview.png)。人工视觉验收不等于所有浏览器兼容性或真实音质验收。

## 交付边界

GitHub Pages 只提供单机静态功能。运行账号与房间需使用完整 Worker 后端；正式部署前要创建 D1、写入真实绑定 ID、应用远程迁移并验证域名。同源部署可沿用现有 Cookie/Origin 校验。

当前仍需完善：正式环境部署与监控、QQ 官方个人库授权、授权实录音源、跨设备/多浏览器验收、账号密码恢复规则。在线统计以服务端每日汇总为准；个人专注完成事件来自客户端，不作为不可伪造的考勤证明。
