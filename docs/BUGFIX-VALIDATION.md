# 历史待验证项：修复与 Chrome 复验

日期：2026-10-31。本记录补充第三至第五天未完成的浏览器验证。修改尚未提交或部署。

## 本轮修复

1. localStorage 在浏览器访问时抛出 SecurityError：原函数默认参数在 try 外读取，可能导致整页初始化失败。改为在保护范围内访问；禁止存储时仍可使用任务、场景和计时，保存失败显示已有提示。
2. 损坏的声音偏好及错误类型开关：读取时规范化声音配置与布尔值，不丢弃有效任务和音乐。
3. 手机转桌面时焦点仍停在已隐藏的面板切换按钮：隐藏前将焦点移到当前内容区域。
4. 音量图标因父层任意换行规则而断成两行：固定图标最小宽度并禁止换行，音量滑块继续自适应。
5. 跨标签页仅切换保留混音等偏好时，声音区控件未同步显示：读取后同步刷新控件，不重置正在播放的音轨。

## 实际浏览器验证

使用本机 Chrome 无界面模式和 Playwright，访问临时本地预览。Playwright 只安装在忽略的 .release-check/ 目录，无新增产品运行时依赖。页面运行使用真实 DOM、CSS、AudioContext 及本地 MP3。

- 320×700、390×844、760×800、844×390、1280×800、1440×900：首页及声音面板未检测到横向溢出。
- 实际创建任务、关联专注、开始计时、切换场景：任务保留，计时截止时间不变。
- 同帧连续切四场景：结束后仅剩一层插画；关闭动画后动画实例为零。
- 雨声、杯碟、咖啡冲煮三轨完成加载并同时处于播放状态；切场景保留三轨。
- 刷新后不自动播放；点击恢复后重新启动三轨。
- 拦截雨声音频请求并模拟断网：该行显示失败，另外两轨继续播放；恢复请求后该行重试成功。
- 延迟雨声请求、点击取消，再放行请求：该轨保持暂停，不复活。
- 恢复已过期的运行中计时：专注完成计数只增加一次，后续 tick 不重复增加。
- 禁止访问 localStorage：页面正常初始化，仍可新增任务。
- 全部场景中未捕获页面 JavaScript 异常。

本地验收脚本：.release-check/browser-audit.mjs；临时服务与 Chrome 在脚本结束后关闭。

## 自动回归

新增存储访问被禁止、偏好损坏恢复，以及手机转桌面焦点的回归断言。现有完整流程、音频取消、加载重试及完成去重继续执行。

结果：22/22 测试通过；36 个 JavaScript 文件与入口检查、静态构建、差异空白检查通过。

## 验证边界

Chrome 无界面验证确认文件加载、解码、播放状态和界面逻辑，不等于有人实际听过音质。尚未覆盖真实手机、软键盘、Safari/Firefox 或真实后台长时间播放。第三至第五天的浏览器启动阻碍已通过独立测试工具绕过，这些历史记录中的“浏览器未验证”由本记录补充；真机及跨浏览器项目仍留在第六天。
