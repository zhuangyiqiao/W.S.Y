# 雨声咖啡馆项目需求说明书

## 1. 项目概述

### 1.1 项目名称

雨声咖啡馆（Rainy Cafe）

### 1.2 产品定位

一个具有沉浸式场景、生活管理和多人陪伴能力的轻量工作台。

用户可以在不同氛围空间中管理任务、进行番茄钟专注、播放环境音和音乐，并与朋友进入同一个房间共同工作或休息。

产品核心体验：

> 选择一个舒服的场景，选一只猫猫，让自己安静地完成一件事。

### 1.3 目标用户

- 需要学习、工作或阅读陪伴的个人用户
- 需要轻量任务管理和专注计时的用户
- 希望与朋友共同在线但不需要持续聊天的用户
- 喜欢环境音、场景化网页和虚拟陪伴的用户

### 1.4 产品原则

- 氛围优先，但不能牺牲基本可用性
- 功能轻量，避免做成复杂项目管理工具
- 多人空间共享状态，不默认泄露个人任务详情
- 音乐平台接入遵守平台能力、跨域限制和版权规则
- 未登录时也可以体验核心场景和本地功能

## 2. 产品范围

### 2.1 首期必须支持

1. 沉浸式场景工作台
2. 四个可切换场景
3. 简单账号注册、登录和记住登录状态
4. 今日任务管理
5. 番茄钟
6. 可选猫猫陪伴
7. 番茄钟结束时猫猫起身并发出喵叫提示
8. 环境音控制
9. 创建房间和加入房间
10. 房间在线成员状态
11. 共享歌单与私人歌单
12. “我的”页面
13. 历史在线热力图

### 2.2 首期不包含

- 复杂项目管理、子任务和甘特图
- 社交好友关系和私信系统
- 用户上传头像、背景和音频文件
- 付费、会员、虚拟商品
- 手机号、邮箱验证和第三方账号登录
- 非官方抓取网易云音乐或 QQ 音乐音频流
- 强制同步所有成员的音乐播放进度

## 4. 场景需求

系统首期提供四个场景。场景切换应改变背景视觉、环境音预设、灯光色调和猫猫所在位置，但不应清空任务或中断用户数据。

### 4.1 雨夜工作台

**场景 ID：** `rainy-room`

视觉元素：

- 夜晚窗户
- 雨滴和城市灯光
- 书桌、台灯、电脑或书本
- 深蓝、灰紫和暖黄色灯光

默认环境音：

- 雨声
- 轻雷
- 键盘声
- 房间白噪声

适用状态：

- 工作
- 学习
- 写作
- 长时间专注

### 4.2 晴天海边

**场景 ID：** `sunny-beach`

视觉元素：

- 晴朗天空
- 海面、沙滩和云朵
- 躺椅、遮阳伞或小桌
- 蓝色、浅黄色和白色调

默认环境音：

- 海浪
- 海风
- 海鸥
- 轻风铃

适用状态：

- 阅读
- 放松
- 轻量任务
- 休息

### 4.3 篝火旁

**场景 ID：** `campfire`

视觉元素：

- 夜晚树林或露营地
- 篝火、帐篷、木箱和折叠椅
- 星星和山影
- 橙色火光与深蓝夜色

默认环境音：

- 木柴燃烧
- 夜间虫鸣
- 风声
- 远处猫头鹰

适用状态：

- 晚间陪伴
- 多人房间
- 阅读
- 放松和睡前使用

### 4.4 咖啡馆

**场景 ID：** `cafe`

视觉元素：

- 咖啡馆室内
- 吧台、书架、桌椅和窗户
- 咖啡机、餐具和暖色灯光
- 棕色、橙色和奶油色调

默认环境音：

- 咖啡机
- 键盘声
- 低声交谈
- 餐具碰撞
- 门铃声

适用状态：

- 日常工作
- 学习
- 写作
- 多人共同专注

### 4.5 场景规则

- 未登录用户可以切换和体验四个场景
- 登录用户保存上次选择的场景
- 房间内由房主或房间权限决定当前场景
- 房间场景统一同步给所有成员
- 猫猫选择由每个成员独立决定
- 场景切换不影响私人音乐播放
- 环境音可由房间提供默认预设，成员可以在本地微调音量

## 5. 猫猫陪伴需求

### 5.1 猫猫选择

首期至少提供 4 只猫猫：

- 小黑
- 煤球
- 奶糖
- 橘子

每只猫猫至少需要：

- 唯一 ID
- 名称
- 默认显示形象
- 空闲动作
- 专注动作
- 休息动作
- 完成动作
- 喵叫音效

### 5.2 状态表现

| 番茄钟状态 | 猫猫表现 |
|---|---|
| 空闲 | 趴着、眨眼、甩尾巴 |
| 专注中 | 安静陪伴、阅读或趴在桌边 |
| 休息中 | 起身、伸懒腰、活动 |
| 完成 | 起身、跳动或摇尾巴、喵叫 |

### 5.3 完成反馈

番茄钟结束时：

1. 停止当前倒计时
2. 播放喵叫音效
3. 播放猫猫完成动画
4. 显示本轮完成提示
5. 增加个人完成番茄钟数量
6. 提供“开始休息”或“继续专注”操作

音效和动画必须可以单独关闭。

---

## 6. 任务管理需求

### 6.1 今日任务

用户可以：

- 新增任务
- 完成任务
- 取消完成
- 删除任务
- 查看今日完成数量
- 将任务关联到当前番茄钟

任务字段：

```text
id
user_id
title
completed
created_at
completed_at
pomodoro_count
```

### 6.2 任务规则

- 任务标题必填，长度建议不超过 120 个字符
- 默认只显示当天任务
- 未登录时可以保存在本地浏览器
- 登录后同步到云端
- 删除任务需要明确操作，不因页面刷新自动删除
- 房间成员默认只能看到“正在专注”状态，不可看到私人任务标题
- 用户可以主动选择是否在房间公开当前任务标题

## 7. 番茄钟需求

### 7.1 基础模式

首期提供：

- 25 分钟专注
- 5 分钟短休息
- 15 分钟长休息
- 自定义时长
- 开始
- 暂停
- 继续
- 重置

### 7.2 专注状态

番茄钟状态：

```text
idle
running
paused
break
completed
```

### 7.3 多人房间中的番茄钟

- 每个人拥有独立番茄钟
- 房间同步成员的状态和剩余时间
- 默认不强制所有成员同时开始
- 房主可以发起“共同开始”
- 共同开始后，每个成员仍可单独暂停
- 断线重连后根据服务器时间修正状态

## 8. 音频与歌单需求

### 8.1 环境音

至少提供：

- 雨声
- 海浪
- 篝火
- 咖啡机
- 键盘声
- 风声
- 白噪声

支持：

- 单独开关
- 独立音量
- 一键静音
- 场景默认音效预设
- 记住个人音量设置

### 8.2 歌单类型

系统提供两种歌单：

#### 房间共享歌单

- 房间成员可以查看
- 根据房间权限添加或删除
- 房间成员可以选择当前歌曲
- 添加者和添加时间可见

#### 私人歌单

- 只有本人可见
- 不同步给其他房间成员
- 可以在房间中独立使用
- 不改变房间共享歌单

### 8.3 音乐平台接入

首期支持保存以下信息：

```text
歌曲名称
歌手
平台
歌曲或歌单 URL
添加者
创建时间
```

平台值：

```text
netease
qq
other
```

接入原则：

- 优先使用官方允许的嵌入播放器
- 如果平台不支持嵌入，则提供外链打开
- 不抓取或代理平台受版权保护的音频流
- 不保存用户平台密码或登录凭证
- 不要求同步所有成员的音乐播放进度
- 每个成员可以在本地独立播放音乐

## 9. 账号与登录需求

### 9.1 注册

采用轻量注册方式：

```text
昵称
密码
```

要求：

- 昵称全局唯一
- 昵称长度 2—20 个字符
- 密码至少 8 位
- 后端只保存密码哈希
- 不保存明文密码

### 9.2 登录

- 使用昵称和密码登录
- 登录成功后创建会话
- 支持“记住登录状态”
- 支持主动退出登录
- 会话过期后要求重新登录

推荐实现：

- HttpOnly Cookie
- Secure Cookie
- SameSite=Lax 或更严格策略
- 服务端 Session

### 9.3 未登录体验

未登录用户可以：

- 浏览四个场景
- 使用本地番茄钟
- 选择猫猫
- 创建本地任务
- 调整环境音设置

需要账号才能使用：

- 云端同步任务
- 创建或加入多人房间
- 保存云端歌单
- 查看云端历史在线热力图

---

## 10. 多人房间需求

### 10.1 房间基础功能

用户可以：

- 创建房间
- 生成 6 位房间码
- 通过房间码加入
- 离开房间
- 查看当前成员
- 查看成员在线状态
- 关闭或解散自己创建的房间

### 10.2 房间成员状态

每个成员显示：

- 昵称
- 在线/离线
- 当前猫猫
- 空闲/专注/休息/暂离
- 当前番茄钟剩余时间
- 是否正在使用共享歌单

默认不显示：

- 私人任务列表
- 私人歌单
- 详细在线时长
- 个人历史数据

### 10.3 房间权限

房主可以设置：

- 是否允许成员添加共享歌曲
- 是否允许成员删除自己添加的歌曲
- 是否允许成员切换共享歌曲
- 是否允许成员发起共同专注
- 是否允许新成员加入

### 10.4 实时同步

建议使用 WebSocket：

- 成员加入/离开
- 在线心跳
- 场景变化
- 猫猫选择
- 番茄钟状态
- 共享歌单变化
- 房间权限变化

断线后：

- 自动尝试重连
- 显示重连中状态
- 重连成功后重新拉取房间快照
- 不将本地私人状态错误广播给其他成员

## 11. 我的页面需求

### 11.1 个人设置

- 昵称
- 默认场景
- 默认猫猫
- 默认番茄钟时长
- 是否播放猫叫
- 是否播放环境音
- 环境音音量
- 退出登录

### 11.2 历史在线热力图

展示最近 365 天的每日活动情况。

每日等级建议：

| 等级 | 条件示例 |
|---|---|
| 0 | 当天没有有效访问 |
| 1 | 登录或进入页面 |
| 2 | 有有效操作或停留 |
| 3 | 完成至少一个番茄钟 |
| 4 | 完成多个番茄钟或有较长有效在线时长 |

每日统计字段：

```text
user_id
date
login_count
online_minutes
completed_tasks
completed_pomodoros
activity_level
```

在线统计规则：

- 登录成功记录当天活动
- 页面有操作时刷新活动时间
- 建议每 5 分钟发送一次心跳
- 连续 10 分钟无操作后停止累计在线时长
- 只保存每日汇总，不保存逐秒轨迹

## 13. 安全与隐私要求

- 所有账号接口必须服务端校验输入
- 密码必须使用安全哈希算法保存
- Session 必须具备过期时间
- 任务、私人歌单和在线数据必须校验所属用户
- 房间码不能直接作为修改权限
- 房间操作必须校验成员身份和房主权限
- 共享歌单 URL 需要限制长度并过滤危险协议
- 前端渲染用户输入时必须转义，避免 XSS
- 不保存第三方音乐平台账号密码
- 不公开个人详细在线轨迹
- WebSocket 消息必须校验消息类型和字段
- 对注册、登录、创建房间和添加歌单接口进行限流

## 14. 开发阶段

### Phase 1：沉浸式单机 MVP

- 四个场景切换
- 场景动画和环境音
- 今日任务
- 番茄钟
- 猫猫选择
- 完成动画和喵叫
- 本地设置保存

验收标准：

- 用户可以在四个场景之间切换
- 场景切换不丢失任务
- 番茄钟可以开始、暂停、重置和完成
- 完成时猫猫出现动画和音效
- 刷新页面后任务、猫猫和设置仍然存在

### Phase 2：账号和云端同步

- 注册、登录、退出
- Session 和记住登录状态
- 任务云端同步
- 个人设置云端同步
- 未登录本地模式和登录模式合并策略

验收标准：

- 新用户可以注册并登录
- 刷新或重新打开页面后保持登录
- 同一账号在不同设备可以看到云端任务
- 退出后无法访问受保护数据

### Phase 3：多人房间

- 创建/加入房间
- WebSocket 实时状态
- 成员列表
- 场景同步
- 猫猫和番茄钟状态同步
- 断线重连

验收标准：

- 两个浏览器可以进入同一房间
- 一方加入或离开时另一方能及时看到
- 场景和成员状态可以同步
- 断线重连后不会丢失房间状态

### Phase 4：歌单和音乐平台

- 共享歌单
- 私人歌单
- 网易云音乐链接保存
- QQ 音乐链接保存
- 官方播放器或外链回退
- 房间歌单权限

验收标准：

- 私人歌单不会出现在其他成员视图
- 共享歌曲可被房间成员按权限添加或删除
- 不支持嵌入时可以安全打开原平台链接

### Phase 5：我的页面和在线热力图

- 个人设置
- 每日在线统计
- 番茄钟和任务统计
- 最近 365 天热力图

验收标准：

- 有效访问可以生成当天活动记录
- 番茄钟完成会更新当天统计
- 热力图颜色等级与活动数据一致
- 用户只能查看自己的历史数据

---

## 15. 非功能需求

### 性能

- 首屏核心内容尽量在 2 秒内可见
- 场景动画不应阻塞任务和计时器
- 环境音加载失败不应阻塞页面使用
- 移动端保持基本可用

### 兼容性

- 支持现代 Chrome、Edge、Safari 和 Firefox
- 适配手机、平板和桌面端
- 处理浏览器自动播放限制
- 音效首次播放必须由用户操作触发

### 可访问性

- 控制按钮提供可读名称
- 键盘可以操作任务和番茄钟
- 颜色不是传递状态的唯一方式
- 猫猫动画和音效可关闭

### 可维护性

- 场景配置与场景渲染逻辑分离
- 房间实时状态与个人本地状态分离
- 音频资源使用统一资源清单
- 所有 API 响应使用统一错误格式
