## 4. 数据及接口补齐

- 保留 V1 八类数据表及 API 领域。音乐枚举增加 spotify，普通链接、官方授权连接与本站登录分开建模。
- 若使用 OAuth，设计发起、回调、状态查询、断开及个人歌单读取流程；选定平台后明确回调域名与 Token 管理。
- 个人设置补齐各音轨音量/开关、主题、猫猫、计时时长、猫叫/动画、上次场景和音乐来源。配置恢复不代表平台已登录。
- 明确任务日期、旧数据迁移、本地/云端合并、专注事件幂等和多设备在线去重。
- 房间权限拆分；计时保存模式、状态、截止时间、暂停余量；补充房间配置/解散/共同开始命令、共享当前歌曲及统计写入流程。
- 当前部署仅 GitHub Pages。B 阶段验证授权相关部署；D 阶段落实完整后端，原文推荐 Workers、D1、Durable Objects，尚未实施。
