# life.ing｜第四天：环境音与自由混音

完成日期：2026-10-31。本地代码与自动检查已完成，尚未提交推送或发布。

## 已实现

- 场景默认展示推荐声音，点击“全部声音”可自由组合六条现有授权录音。非推荐但正在播放、加载或失败待重试的声音仍保持可见。
- “播放场景推荐”重置为当前场景的默认组合；“恢复上次混音”播放保存的启用音轨和音量。刷新只恢复配置，点击后才发声。
- “切场景保留混音”保留当前组合，否则优先恢复新场景个人配置，无个人配置才使用场景预设。保存过的全静音组合不被默认音轨覆盖。
- 音轨独立播放、暂停、音量和加载取消；失败提示留在对应音轨下，支持单独重试，不阻塞其他声音。网络请求增加 20 秒超时，失败缓存清除后可重新请求。
- 新增 sound-controller.js，将场景声音偏好、播放请求代次与 UI 分离。取消、快速切换及音频解锁过程中退出的旧请求不会复活音轨。
- 环境音静音仍独立于音乐链接和猫叫提示；播放和音量保留现有渐变。
- 偏好沿用原本地存储；关闭保存会清除已保存声音配置。跨标签页读取配置不自动播放。
- 声音来源面板展示全部六条现用录音作者、源页面、许可与修改说明，覆盖自由混音中的非场景推荐素材。

## 素材边界

继续使用 manifest.json 和 CREDITS.md 中的六条本地录音；本轮没有引入新音频或外部直链。现有文件哈希、来源及许可一致性由测试核对；未重新联网核验源网站，也未将候选素材当作已采用素材。呼噜、翻书及每场景六轨继续留在后续素材清单。
