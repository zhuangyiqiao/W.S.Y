## 推荐渠道

| 渠道 | 使用方式 | 适合内容 |
| --- | --- | --- |
| [Freesound](https://freesound.org/help/faq/#licenses) | 每条筛选 CC0 或 CC BY；CC BY 保留作者及许可署名，避免把 CC BY-NC 当作通用商业许可 | 雨、海浪、风、虫鸣、火焰、室内底噪、咖啡机 |
| [OpenGameArt CC0 Sounds Library](https://opengameart.org/content/cc0-sounds-library) | 从集合进入具体作品页，再核对文件与许可；集合本身不是统一下载包 | 餐具、流水、煮水、海浪、短促动作声 |

不把 [Sonniss GDC](https://sonniss.com/gdc-bundle-license/) 当作开源库：其当前条款是专有授权，限制声音素材本身的供应/再分发。对以环境声音播放为主的网站，不能仅凭“免费可商用”就推断适用。本版不采用该素材。

## 素材进入项目的流程

1. 在作品页核对并记录作者、原始 URL、许可版本、下载日期和允许的再分发方式。
2. 保存许可证记录，听检是否含音乐、清晰可辨的私人对话、突发高音量或其他不适合作背景的内容。
3. 为持续底层制作循环与交叉淡入淡出；门铃、翻页、鸟叫等单次声音使用间歇调度，不机械地密集重复。
4. 输出浏览器支持的音频格式，限制单条长度与峰值。小样可放 assets/audio；录音较多时放对象存储，不把大体积 WAV 塞入 Git 历史。
5. 在 `sound-catalog.js` 中为音轨添加 src 及实际采用的作者/许可记录；候选与已使用状态必须区分。
6. `audio.js` 已支持加载 src。录音不应经过现有合成音的低通预设，因此文件音轨会绕过合成滤波；使用录音前仍需试听验收。

页面“声音来源与授权”会显示渠道和当前场景候选。候选状态不代表实际使用，实际署名表应随素材一起更新。
