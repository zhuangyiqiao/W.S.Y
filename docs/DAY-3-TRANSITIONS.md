# life.ing｜第三天：场景切换与猫咪状态

完成日期：2026-10-31。本地实现及自动验收已完成；浏览器视觉验收待补。

## 本轮实现

- 新增 scene-controller.js：约 320ms 双层交叉淡化，快速切换取消过期动画，结束后仅保留当前插画。旧图层隐藏于辅助技术，避免重复朗读。
- 场景或猫咪改变才替换插画；主题、动画开关和每秒计时更新不重建 SVG，不触碰音乐区、任务或计时数据。
- SVG 外层固定落脚位置，内层表现状态：空闲轻微呼吸、专注伏低并停止甩尾、休息伸展、完成起身及短暂跳动。长短休息均映射到休息状态，暂停回到空闲。
- 保留猫叫与动画独立开关。关闭动画或系统切换为减少动画偏好时立即结束场景淡化；CSS 禁止持续动作。静态状态和提示文案继续可见。
- 延续已有计时完成去重与喵叫机制；开始下一轮或重置会清理完成动画，避免延迟回调干扰新状态。
- 给场景音轨恢复循环增加代次检查，快速切换时不继续执行旧场景的后续音轨；已取消的加载结果不修改新场景的音轨状态。
