## 3. 技术方案

- 原生 HTML/CSS/JavaScript ES Modules；不增加前端框架。
- SVG 统一坐标系，以场景配置保存猫咪位置、缩放和姿态；原创插画继续沿用。
- Web Animations API 实现约 300ms 交叉淡化，处理快速连点和减少动画偏好。
- Web Audio API 复用 SoundMixer，保留多轨、独立音量、循环、静音及取消加载行为。
- 场景推荐与全部可用声音分开：默认展示合理推荐，自由混音入口提供全部已核验音轨。
- 换场景优先恢复该场景个人配置；可选保留当前混音。未主动播放时不自动出声。
- localStorage 保留原存储键和迁移备份；切换场景不清空任务、不重置计时、不重建音乐区。
- 使用 Node.js 现有检查和测试；浏览器验收可使用 Playwright，覆盖快速切换与移动端。
- 发布继续使用 GitHub Actions → public/ → GitHub Pages。Cloudflare Worker/D1/Durable Objects 为完整应用后续路线，本周不迁移托管。
